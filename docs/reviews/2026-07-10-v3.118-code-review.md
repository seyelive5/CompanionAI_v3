### F1. TurnEnding 포인트 시전(Overwatch/Veil of Blades) 사멸 — CONFIRMED

- **앵커**: `Core/TurnPlan.cs:215-233` (NeedsReplan 1-3b), `Execution/ActionExecutor.cs:281-303` (백스톱), 부속 `AIConfig.cs:20` (MaxPlayerAlliesHit 기본 0).
- **메커니즘**: `PlannedAction.PositionalAttack`(Core/PlannedAction.cs:249) = `ActionType.Attack` + 포인트 TargetWrapper + AllTargets null → 두 게이트 술어와 정확히 일치. `BuffPlanner.PlanTurnEndingAbility`(BuffPlanner.cs:1577-1621)는 Overwatch(`a77c8eee`, DB:106 `TurnEnding, PointTarget|IsDefensiveStance`)를 전방 5m, VeilOfBlades(`8b7bcaa0`, DB:350)를 1.5m 오프셋 포인트로 계획 — **적 점유 의도가 없는 시전**(오버워치는 다음 턴 진입 감시가 목적). Overwatch 블루프린트는 PatternSettings 보유 → `TryCountUnitsInPattern`이 true + 적 0 반환 → fail-open으로 구제 안 됨.
- **실패 시나리오**: Overwatch가 큐 헤드 도달 → 1-3b 매 폴 "no longer hits any enemy" → replan이 동일 플랜 재생성 → StagnantPlanCount 3회 → 강제 EndTurn, **Overwatch 영구 미시전** (v3.117.98에선 정상). 실행 도달 시에도 백스톱이 `Failure("No enemies in AoE pattern at target point")` abort. 적이 콘 안에 있어도 아군이 함께 있으면 IsAoESafe(MaxPlayerAlliesHit=0)가 3차 차단 — 오버워치는 시전 시점에 아군을 해치지 않는데도.
- **파급**: `MovementPlanner.cs:1134`(SoldierDash 후퇴), `:322/:447`(도약 착지)도 같은 술어 — 해당 블루프린트에 PatternSettings 있으면 동일 차단(없으면 Empty 패턴 → fail-open).
- **수정 방향**: 게이트에서 의도 기반 면제 — 빠른 수정: `AbilityDatabase.GetInfo`로 `Timing==TurnEnding || HasFlag(IsDefensiveStance)` 면제(두 게이트 모두). 구조 수정: PositionalAttack 생성부에서 "적 점유 요구" 여부를 PlannedAction 플래그로 명시하고 게이트는 플래그만 검사. **양방향 점검 필수**: 면제가 진짜 데미지 포인트 AoE(Fix E 대상)를 다시 열지 않는지.
- **검증**: 수정 전 GameLogFull에서 `point AoE Overwatch|Veil` grep — 발생 중이면 실증. 수정 후 Overwatch 시전 로그 복귀 + §9의 정당 차단 2건(Machine Spirit Communion 등)은 유지.
