## 안전 확인 (직독으로 확인, 결함 아님)

- **F5 동일 함수 전제**: FindBestAerialRushPath 수락 기준은 3-인자 Bresenham `CountEnemiesInChargePath`(:952 `enemyCount<=0 → continue`),
  agent 오버로드(:1144, FamiliarSupport:1109)는 랭킹/추정용. Bresenham 내부가 `!IsConscious` 를 자체 필터하므로 plan(`situation.Enemies`)과
  게이트(`liveEnemies`) 카운트 일치 → false-abort 없음. `situation.Enemies`(GetEnemies)는 사망 제외.
- **F1 백스톱 전체 제외의 정당성**: `AoESafetyChecker.IsAoESafe` 는 반경>0 이면 피해 여부와 무관하게 아군 포함을 실패로 판정 →
  Overwatch/Veil(반경>0 존)에 아군 검사를 적용하면 아군 근처 시전이 차단(F1 3중 차단의 한 축). 후퇴 대시도 아군 근처 착지가 정상.
  따라서 flag=false 는 블록 전체 제외가 맞음. (착지 AoE 피해가 있는 대시의 아군 안전은 v3.118.0 이전부터 plan-time 미검사 — 별도 관찰)
- **F2/F12 zero-AP count 일관성**: 스냅샷(CreatePlanWithSnapshot·TurnPlanner 폴백)과 NeedsReplan 3-4(TurnPlan:334) 모두 기본 Adaptive.
  3-4 는 `>`(증가)만 트리거 → HP 하락으로 자해 0-AP 가 게이트되어 count 가 줄어도 허위 replan 없음. `CanAnyZeroAPAttackReachEnemy` 도
  게이트된 목록 사용 → AP=0 continue 경로 일관.
- **F7 시맨틱**: 플랜-로컬 `usedWarpRelay=true` 는 keystone(relay 대상) 능력 계획 시 set — `HasExecutedAbilityMatching(IsWarpRelayTarget)`
  (성공 실행만)과 의미 일치.
- **F6 GetRangePreference**: 7곳 전부 자기 유닛 컨텍스트(GetWeaponRangeProfile/CountHittableEnemiesFromPosition/포지셔닝 평가) —
  적 유닛에 GetOrCreateSettings 를 만들지 않음. 자동 저장 없음(SaveRoutine 시만).
- **F3 롤백**: `HasEvacuatedThisTurn=false` 롤백은 F3 게이트상 이번 턴 첫 대피만 가능하므로 안전. 실패 Move = ExecutedActions 마지막 Move 보장
  (MoveTo 반환 후 같은 틱 다른 액션 없음).
- **틱 변형 stash**: decision node 가 사역마 스킵 → 그 뒤 Set/Clear(try/finally) → 유닛ID 가드. Sequence 재시작 전까지 UnitMoveVariants 불변이라
  Analyze/Plan 프레임 간 일관. 게임 dict Length 는 위협 페널티 포함 메트릭(실증: 물리 2MP=6.0)이라 **blanket 대체 금지**(MP 예산 왜곡) — 대피 전용이 맞음.
- **SetupMovement standable-walk**: ParentNode 체인은 유한 트리(루트 null) → 종료 보장.
- **회귀**: 삭제 팩토리 2개 호출자 0(빌드), 리네임 콜러 전부 갱신, :833 리팩토링 원 조건과 동치, F13 GUID 중복 없음.
